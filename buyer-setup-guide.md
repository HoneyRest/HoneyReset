# Honey Reset — Buyer setup guide

## What this product is

**Honey Reset** is a **private web app**—a calm companion for a new chapter (postpartum, relocation, separation, or any major reset). One page runs entirely in your browser.

This is a **private web app. No login, no subscription.** Your entries save **locally in your browser** on the device you use.

---

## How to open the hosted app link

Use the URL your seller provides (for example a **GitHub Pages** link):

`https://your-name.github.io/your-repo-name/`

Open it in **Safari** on iPhone or **Chrome / Safari / Firefox** on desktop. The site loads **index.html** automatically.

---

## Add to Home Screen (iPhone / iPad)

1. Open the link in **Safari**.
2. Tap **Share** → **Add to Home Screen**.
3. Tap **Add**.

---

## Use on desktop

Bookmark the hosted URL or open **index.html** from your downloaded folder. Your data stays in that browser.

---

## Privacy & local storage

**This is a private web app. No login, no subscription.** Your entries save **locally in your browser** on the device you use.

### Important warning

**If you clear browser data or switch devices, export a backup first.**

---

## Backup & restore (export / import)

### Export

Use the app’s **Export backup** (or similar) control. Downloads are typically named **`honey-reset-backup.json`**. Keep copies somewhere safe.

### Import

Use **Import backup** and select a JSON file **exported from Honey Reset**. Import usually replaces existing data in that browser—read any confirmation dialogs carefully.

---

## Troubleshooting

| Issue | What to try |
|--------|----------------|
| Page won’t load | Check the URL; try another browser; hard refresh. |
| Lost data | Restore from **`honey-reset-backup.json`** if you exported one. |
| Icon wrong on home screen | Redeploy with **honey-icon.png** next to **index.html**. |
| Incognito / Private mode | Prefer a normal browsing window for persistent storage. |
